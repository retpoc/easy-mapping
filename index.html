คำถาม
ที่เจอบ่อย

        
ยังติดตรงไหน ทักคุณคอปที่ Prush ITM ได้เลย

        

      

      

        
applicationId ไม่ซ้ำได้อย่างไร
          
เว็บใช้ทุกหลักของ applicationId ใน Template ยกเว้น 3 ตัวท้ายเป็น prefix แล้วสุ่ม 3 ตัวท้ายเฉพาะในช่วงเลขของคุณ เช่น เลือก 3 จะได้ 300 ถึง 399 และข้ามเลขที่เคยใช้แล้ว ถ้าทุกคนเลือกช่วงไม่ซ้ำกัน เลขจะไม่ชนกันเลย ถ้าล็อกอิน Claude ด้วยบัญชีที่มีสิทธิ์ เว็บจะจองเลขบน cloud ซ้ำอีกชั้น
เลข 3 ตัวท้ายของ Template เอง (745 ของ Auto และ 582 ของ Mortgage) จะถูกข้ามไปเสมอ แต่ละเส้นมี prefix ของตัวเองจึงนับเลขแยกกัน และ ncbTransactionId จะได้เลขเดียวกับ applicationId

        
rquId ของสองเส้นเปลี่ยนต่างกันอย่างไร
          
Auto ใช้ rquId 31 ตัว เว็บสุ่มเลือก 5 ตำแหน่งจากทั้งเส้น ส่วน Mortgage ใช้ rquId 32 ตัว เว็บเปลี่ยน 5 ตัวท้ายเสมอ ทั้งสองแบบ ตำแหน่งที่เป็นตัวอักษรจะได้ตัวอักษรตัวใหม่ ตำแหน่งที่เป็นตัวเลขจะได้ตัวเลขตัวใหม่ และความยาวเท่าเดิม
ถ้าทีมใช้อีกวิธี สลับได้ที่การ์ด rquId เว็บจะจำแยกตามเส้น

        
Auto กับ Mortgage ใช้ฟิลด์ต่างกันอย่างไร
          
Mortgage ไม่มี middleName, middleNameEn, receiveEmail และ rmID ใน borrowerInfo ส่วน loanInfo เป็นแบบสินเชื่อบ้าน (Mortgage · NEWHOME · mfDeveloperCode) ไม่มี collateralDetails
เว็บใช้ Template ของเส้นที่เลือกเป็นโครง จึงไม่เติมฟิลด์ที่เส้นนั้นไม่มี ดูตารางเทียบได้ที่ส่วนแผนผังการ Map

        
ถ้า response มีลูกค้ามากกว่าหนึ่งราย
          
ใต้ช่องวางจะมีเมนูให้เลือกว่าจะใช้ลูกค้ารายไหน ค่าเริ่มต้นคือรายแรก ถ้า referenceInfo มีหลายรายการ เว็บจะเลือกรายการที่เป็น P1 ก่อน

        
ถ้า API ไม่มีค่าบางฟิลด์
          
เว็บจะใส่ค่าว่างแทน (monthlyIncome จะเป็น 0) และทำสีเหลืองไว้ทั้งในผลลัพธ์และในแผนผัง จะไม่ใช้ค่าเดิมจาก Template เพราะเป็นข้อมูลของลูกค้าคนอื่น

        
rmID กับที่อยู่ตามบัตรมาจากไหน
          
rmID ใช้ตัวท้ายของ customerKey ยาวเท่ากับ rmID ใน Template (14 หลัก) มีเฉพาะเส้น Auto ส่วนที่อยู่ตามบัตรใช้ primaryAddress ฝั่งภาษาไทย ทั้งสองอย่างเป็นฟิลด์เสริมที่ปิดไว้ ลองเทียบกับระบบจริงก่อนเปิดใช้

        
ประวัติเลขเก็บไว้ที่ไหน
          
เก็บในเบราว์เซอร์ของแต่ละคน เว็บนี้ไม่มี server กลาง จึงไม่มีใครเห็นประวัติของคนอื่น ช่วงเลขส่วนตัวเป็นตัวกันไม่ให้เลขชนกับเพื่อน
ถ้าใช้หลายเครื่องหรือหลายเบราว์เซอร์ ให้เลือกช่วงเลขคนละช่วง และถ้าล้างข้อมูลเบราว์เซอร์ ประวัติเลขจะหายไปด้วย ควรย้ายไปใช้ช่วงใหม่หลังจากนั้น

        
ไม่ได้ล็อกอิน Claude ใช้ได้ไหม
          
ใช้ได้ทุกอย่าง ทั้ง Map ข้อมูล สร้างเลข และคัดลอก JSON ต่างกันแค่ประวัติเลขจะเก็บไว้ในเบราว์เซอร์ของคุณ ไม่ขึ้นบน cloud ให้ทีมเห็น ช่วงเลขส่วนตัวจึงสำคัญ เพราะเป็นตัวกันไม่ให้เลขชนกับเพื่อน
ถ้าใช้หลายเครื่อง ให้เลือกช่วงเลขคนละช่วงในแต่ละเครื่อง เพราะเครื่องหนึ่งไม่รู้ว่าอีกเครื่องใช้เลขไหนไปแล้ว

        
รหัสเข้าเว็บกันอะไรได้บ้าง
          
กันคนที่บังเอิญได้ลิงก์ไปไม่ให้ใช้งานได้ทันที แต่ไม่ใช่ระบบความปลอดภัย เพราะเบราว์เซอร์เป็นคนตรวจรหัส คนที่เปิดดูโค้ดของหน้าเว็บข้ามไปได้ จึงใช้กับข้อมูลทดสอบเท่านั้น ใส่รหัสถูกครั้งเดียว เบราว์เซอร์นั้นจะจำไว้ กด “ล็อกหน้านี้” ท้ายหน้าเพื่อให้ถามรหัสอีกครั้ง

        
เว็บยิง Workflow ให้เลยได้ไหม
          
ไม่ได้ เว็บนี้เตรียม JSON ให้คัดลอกไปยิงใน Postman เอง เพราะระบบ SIT อยู่ในเครือข่ายภายใน เว็บไม่ได้ต่อกับ API หรือ Workflow ใด ๆ
